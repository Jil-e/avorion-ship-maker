# 🚀 Avorion Ship Maker

Процедурный генератор чертежей кораблей для игры **Avorion**. Опишите корабль
словами (по-русски или по-английски) и/или задайте параметры — получите 3D-превью
и готовый файл `.xml`, который загружается в игре.

*A procedural Avorion ship-blueprint generator: describe a ship in words
(Russian or English), tweak parameters, get a 3D preview and a game-ready `.xml`.*

---

## Возможности

- **Текст → корабль.** Двуязычный парсер понимает класс («истребитель», «крейсер»,
  «линкор», «грузовик»…), стиль, компоновку («катамаран», «с гондолами», «с надстройкой»),
  цвета, размеры, число двигателей, крылья/кили/мостик.
- **Разнообразные корпуса.** Корпус собирается из 2–5 продольных секций с разными
  сечениями (ступенчатые «террасы» или плавные переходы), нос — один из четырёх типов
  (игла/зубило/лопата/таран), компоновка — **монокорпус / катамаран / гондолы /
  надстройка** (авто от seed с весами по классу, либо вручную). Двигатели
  распределяются по корме каждого корпуса/гондолы.
- **Скос рёбер (клинья).** Выпуклые рёбра/углы корпуса скругляются блоками-клиньями
  (Hull/Armour Edge & Corner) с корректной ориентацией — гладкий силуэт как в игре
  (в реальных кораблях Avorion ~46% блоков это формы, а не кубы). Ориентация клиньев
  откалибрована по эталонному `arrow.xml` из файлов игры.
- **Баланс «функциональность ↔ красота».** Слайдер наполняет интерьер рабочими блоками
  (генераторы/батареи — на корме, гироскопы/поле целостности/щит — в центре, каюты
  и трюм — в носу, маршевые/рулевые двигатели — на бортах), масштабируя ∝ объёму.
- **Тиринг материалов** по ролям: внешняя броня выше тиром, интерьер ниже.
- **Параметры.** Класс, стиль, длина/ширина (0=авто), высота **относительная** (0=авто,
  ±N — выше/ниже), **шаг** и **масштаб**, материал (железо…аворион), угловатость, броня,
  детализация, **скос**, **функциональность**, seed, ручные цвета.
- **Выступающие части.** Крылья (стреловидные), кили и мостик реально выступают из корпуса
  и прилегают к обшивке; форма корпуса и частей варьируется от seed.
- **Корректный формат.** Байт-в-байт формат Avorion (UTF-8, CRLF, табы, порядок
  атрибутов, дерево связности `parent`/`index`). Семантика блоков и ориентации сверена
  напрямую с файлами игры (`data/plans`, `data/scripts/plangenerator`).
- **Интерактивное 3D-превью на WebGL** (Three.js) — вращение/зум мышью, клинья
  рисуются настоящими призмами. Если встроенный 3D не отобразился (санитайзер),
  рядом есть кнопка открыть превью-`.html` в браузере.
- **Живое обновление**: изменение любого ползунка/поля сразу перестраивает модель;
  кнопка «🎲 Сгенерировать новый вариант» каждый раз бросает новый seed — новый облик;
  строка «🔎 Понято» показывает, что распознано из описания.
- **UI на Gradio** + CLI для скриптов (CLI-превью — PNG через matplotlib).

## Установка

```bash
pip install -r requirements.txt
```

## Запуск интерфейса

```bash
python main.py
```

Откроется локальная веб-страница. Введите описание, при желании раскройте
«Размеры», «Форма и части», «Материал и цвета», нажмите **Сгенерировать корабль**,
покрутите камеру и скачайте `.xml`.

## CLI

```bash
python -m avorion_ship_maker.cli "большой военный крейсер, синий, 3 двигателя" -o cruiser.xml
python -m avorion_ship_maker.cli "long white freighter" --scale 1.5 --png preview.png
```

## Python API

```python
from avorion_ship_maker import generate, save_xml
from avorion_ship_maker.preview import save_preview

ship = generate("маленький красный истребитель с крыльями", scale=1.0, seed=1)
save_xml(ship, "fighter.xml")
save_preview(ship, "fighter.png")
```

## Как загрузить в Avorion

1. Скопируйте `.xml` в папку сохранённых кораблей Avorion
   (`%APPDATA%/Avorion/ships/`), **или**
2. В игре в режиме строительства (Build Mode) используйте
   **Load Ship / Загрузить корабль → из файла** и выберите `.xml`.

> Геометрия и типы блоков валидны и импортируются. Это **дизайн-инструмент**:
> баланс тяги/энергии для реального полёта не гарантируется — доведите корабль
> в редакторе при необходимости.

## Структура проекта

```
avorion_ship_maker/
├── model.py          # Block / ShipModel (AABB-блоки)
├── blocks.py         # реестр типов блоков Avorion (index ↔ роль/имя)
├── connectivity.py   # дерево связности parent/index по смежности граней
├── xml_io.py         # сериализация/парсинг .xml (точный формат игры)
├── preview.py        # 3D-рендер (matplotlib)
├── app.py            # веб-интерфейс (Gradio)
├── cli.py            # командная строка
└── generator/
    ├── spec.py        # ShipSpec + пресеты классов и стилей
    ├── text_parser.py # описание → ShipSpec (RU/EN)
    ├── palette.py     # работа с цветом
    ├── voxel.py       # воксельная сетка + жадное слияние в блоки
    └── builder.py     # ShipSpec → ShipModel (сборка корпуса)

models/               # эталонные корабли-образцы (изучены для формата)
```

## Проверка в игре

Папка `test_ships/` содержит корабли для валидации:
- `wedge_test_frigate.xml` — сгенерированный фрегат со скосом (проверить ориентацию клиньев в игре);
- `arrow_roundtrip.xml` — эталонный `arrow.xml` из игры, пересохранённый нашим сериализатором
  (если грузится ровной стрелой — формат и ориентация верны).
